# PabloCyberSec — Validador de Certificados

Projeto estático pronto para GitHub Pages.

### Teste
`PCS-EHCS-2026-0001` → mostra **Pablo Cyber** e **Ethical Hacking e Cybersecurity**.

Os outros 99 códigos estão no `certificados.json`, porém sem nome, então retornam **Código inválido / não existe aluno cadastrado**.

### Publicação
1. Crie um repositório público no GitHub.
2. Envie `index.html`, `style.css`, `app.js` e `certificados.json`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Salve e aguarde a publicação.

### Importante
Como GitHub Pages é público, o JavaScript e o JSON podem ser vistos por qualquer pessoa. Não coloque CPF, documentos, e-mails privados ou outros dados sensíveis.

Para uma versão de produção realmente robusta, use backend/API ou assinatura digital e não dependa apenas de um JSON público.
